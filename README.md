# Narvex — Landing antirrobo vehicular

Tema Shopify nativo para una landing de un solo producto, con diseño minimalista premium.

## Instalación
1. Conecta este repositorio desde Shopify > Tienda online > Temas > Agregar tema > Conectar desde GitHub.
2. Selecciona la rama main y añade el tema como tema no publicado.
3. En el editor de temas, selecciona el producto real en la sección Narvex Antirrobo.
4. Añade fotografías propias del dispositivo y su instalación.
5. Comprueba variantes, precio, disponibilidad, envío y método de pago contra entrega antes de publicar.

## Importante
El precio promocional previsto es $79.900 COP. El tema utiliza el precio real del producto seleccionado en Shopify; confirma que el precio del producto coincida.
No se hacen promesas de protección absoluta contra el hurto. El dispositivo se presenta como medida adicional de disuasión.
